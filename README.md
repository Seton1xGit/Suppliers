# Поставка

Сервис для поиска поставщиков ингредиентов, готовой продукции и упаковки. Можно выбрать товар и регион доставки, сравнить 2-4 компании, сохранить поставщика и написать личную заметку.

[Открыть сервис](https://suppliers.178-236-242-240.sslip.io/) | [Репозиторий](https://github.com/Seton1xGit/Suppliers)

## Как пользоваться

Введи товар или название компании. При необходимости выбери категорию и город доставки. Совпадения по общей группе товаров отмечены отдельно: наличие конкретного товара нужно уточнять у поставщика.

В блоке цены можно выбрать товарное предложение, порядок цен и фильтр опубликованных цен. Розничные и оптовые цены, разные единицы, НДС и ценовые ступени сравниваются отдельно. Пересчет за килограмм доступен только при подтвержденной массе. Цена товара и стоимость доставки показаны раздельно.

Нажми название компании, чтобы открыть контакты, источники и условия. Добавь 2-4 компании кнопкой "Сравнить". В таблице сравнения закреплены параметры и названия, есть режим "Только отличия". На телефоне таблица прокручивается по горизонтали.

Сохраненные компании и заметки остаются в этом браузере. В верхней панели доступны семь оформлений и кнопка "Как пользоваться" для повторного запуска подсказок.

## Запуск и проверки

Нужен Node.js 22 или новее. Для импорта цен нужен Python 3.10 или новее, дополнительные Python-пакеты не требуются.

```sh
npm install
npm run dev
```

Локальный адрес: http://127.0.0.1:4173. Для размещения достаточно статического HTTP-сервера и содержимого `public`.

```sh
npm run validate
npm test
python -m unittest discover -s tests -p '*_test.py'
npx playwright install chromium
npm run test:browser
node tests/prices-browser.mjs
node tests/comparison.mjs
node tests/dialogs.mjs
```

Для проверки опубликованного сайта задай переменную `TEST_URL`. Снимки браузерных проверок сохраняются в игнорируемую папку `test-results`.

## Данные и обновление

В каталоге 105 компаний. На 2 ноября 2026 года опубликовано 1436 товарных предложений, из них 1435 с числовой ценой у 11 компаний. По направлениям компаний: 478 цен ингредиентов, 197 готовой продукции, 760 упаковки. Одна запись содержит противоречие источников и не участвует в ценовом порядке.

`public/data/catalog.json` содержит компании, контакты и условия со ссылками на официальные источники. `manual-offers.json` хранит ручные предложения, `imported-offers.json` партии открытых прайсов. Общая витрина `offers.json` объединяет обе части. Источники, даты и результаты импорта находятся в `price-sources.json`.

```sh
python scripts/import_prices.py --source food-star
python scripts/import_prices.py --source sibprod
python scripts/import_prices.py --source cake-me
python scripts/import_prices.py --source packtochka
python scripts/import_prices.py --source leopak
```

Повторный импорт заменяет свою партию и сохраняет ручные предложения. Без `--source` обновляются все подключенные источники. При ошибке источника файлы не публикуются. `--input` позволяет проверить парсер на сохраненном содержимом источника: HTML для обычных страниц, JSON-массив HTML для ПакТочки, JSON товаров для Cake Me.

ПакТочка показывает начальную цену от одной единицы, объемные скидки перечислены в условиях. Леопак загружается из открытых разделов пищевой упаковки с выбранным городом витрины Москва; применимость цены к другим городам требует подтверждения. Сибирский продукт содержит розничные цены Новосибирска. Cake Me использует публичный JSON витрины с пагинацией. Неизвестная единица продажи сохраняется без пересчета.

При изменении компании сохраняй ее `id`: к нему привязаны заметки и выбор. У новых условий указывай `value`, `sourceUrl`, `evidence`, дату проверки и источник в `sources`. Город офиса не подтверждает доставку. После обновления запускай валидацию.

## Ограничения

Цены являются снимком открытых источников. Наличие, итоговую стоимость, НДС и условия заказа нужно подтвердить у продавца. Каталог не покрывает весь ассортимент компаний. Минимальный заказ известен у 21 компании, сведения о документах у 2, география доставки у 62. Действительность сертификатов по конкретной партии не проверяется сервисом.

Регистрации, синхронизации между устройствами и рейтинга качества нет. При запрете localStorage данные сохраняются только до закрытия страницы. Автоматическое расписание обновлений и частные API поставщиков не подключены. Для будущего API адаптер должен возвращать тот же формат предложений; секреты должны оставаться на сервере.

## Размещение

`scripts/deploy-server.sh` проверяет конфигурацию Caddy и HTTPS, сохраняет предыдущий релиз и возвращает его при ошибке. Загрузи `public` в новую папку релиза, затем выполни на сервере:

```sh
sh /home/deploy/suppliers/deploy-server.sh /home/deploy/suppliers/releases/<release>
```

Ручной откат выполняется переключением `current` на предыдущую папку `releases/<release>`. Секреты и SSH-ключи хранятся вне репозитория.
